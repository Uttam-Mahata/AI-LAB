
======================================================================
8-PUZZLE PROBLEM SOLVER USING HILL CLIMBING APPROACH
======================================================================

Problem Description:
Hill Climbing is a local search algorithm that:
1. Starts from the initial state
2. Evaluates all neighboring states
3. Moves to the neighbor with the best (lowest) heuristic value
4. Repeats until goal is reached or no better neighbor exists

Limitation: Hill Climbing can get stuck at local optima.
Solution: Use Hill Climbing with Sideways Moves or Random Restarts.

======================================================================
KEY OBSERVATIONS
======================================================================

✓ Advantages of Hill Climbing:
  • Very fast for simple problems (fewer nodes expanded)
  • Low memory requirements
  • Simple to implement and understand

❌ Limitations of Hill Climbing:
  • Can get stuck at local optima
  • May fail to find a solution even when one exists
  • Not guaranteed to find the optimal solution

💡 Improvements:
  • Hill Climbing with Sideways Moves: Helps escape plateaus
  • Random Restart: Try multiple starting points
  • Simulated Annealing: Allow occasional uphill moves

✓ Advantages of A* Search:
  • Guaranteed to find optimal solution (if exists)
  • Complete: Always finds solution if one exists
  • Uses admissible heuristics effectively
